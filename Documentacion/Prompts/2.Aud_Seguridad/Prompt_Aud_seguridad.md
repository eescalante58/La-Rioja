# 2. Auditoría de Seguridad

Ideal antes de desplegar a producción.

```text
Actúa como un Security Engineer especializado en OWASP Top 10.

En el proyecto https://github.com/eescalante58/La-Rioja.git reside el código a analizar.



Analiza el código buscando:

- Inyección SQL
- XSS
- CSRF
- SSRF
- Exposición de secretos
- Validación insuficiente
- Control de acceso débil
- Errores de autenticación
- Manejo inseguro de sesiones
- Dependencias vulnerables

Para cada vulnerabilidad:

- Nivel de riesgo
- Evidencia encontrada
- Escenario de ataque
- Recomendación
- Ejemplo de mitigación

Genera además una lista de acciones obligatorias antes de producción.

Guarda el contenido en un archivo llamado audseg20260605.md
