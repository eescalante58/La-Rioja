# 6. Auditoría de Código Generado por IA

Este es probablemente el más valioso para Windsurf.

```text
Actúa como un Staff Software Engineer revisando código generado por IA.

En el proyecto https://github.com/eescalante58/La-Rioja.git reside el código a analizar.

Analiza el código con especial atención a:

- Suposiciones incorrectas
- Funciones innecesarias
- Sobreingeniería
- Dependencias evitables
- Código repetitivo
- Falta de manejo de errores
- Casos límite no contemplados
- Seguridad
- Escalabilidad
- Mantenibilidad

Indica específicamente:

1. Qué partes parecen generadas por IA.
2. Qué problemas podrían aparecer en producción.
3. Qué código eliminarías.
4. Qué refactorizaciones aplicarías.
5. Si aprobarías este código para producción.

Finaliza con:

VEREDICTO:
- Aprobado
- Aprobado con cambios
- Rechazado
